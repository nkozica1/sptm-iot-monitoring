"Simulation of Processes in Telecommunication Networks"
in the 2026/2027 academic year.

## Project Description

This project focuses on the simulation of an IoT sensor
network for monitoring critical water supply infrastructure
using the ns-3 network simulator.

The proposed network consists of sensor nodes connected
to a Wi-Fi access point and a central monitoring server.
Sensor nodes generate periodic measurements and alarm
messages using UDP communication.

## Simulation Scenarios

- Different numbers of sensor nodes
- Different packet generation intervals
- Wi-Fi error-rate models
- Different mobility models
- Network congestion caused by background traffic
- Multiple simulation runs and model validation
